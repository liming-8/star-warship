# 🚀 星空战舰（Star Warship）

一款使用 HTML5 Canvas 编写的 2D 太空射击游戏：驾驶你的战舰在宇宙中迎击一波波敌方舰队，使用**子弹**与**追踪导弹**摧毁敌舰，争夺高分与最快通关记录。

- 纯前端实现，无任何依赖，双击即可运行
- 支持键盘 / 鼠标双操作
- 内置**个人排行榜**与**全体排行榜**（全体榜需配置云端，见下文）

---

## 🎮 操作说明

| 操作 | 按键 |
| --- | --- |
| 移动 | W A S D / 方向键 / 鼠标 |
| 射击 | 空格 / 鼠标左键（按住连发） |
| 导弹 | X 键 / 鼠标右键（自动追踪、范围伤害） |
| 暂停 | P |
| 静音 | M |
| 排行榜 | 主菜单按 T，或点击「排行榜」按钮（游戏中按 T 会暂停并打开） |
| 修改昵称 | 主菜单按 N |

## 🏆 排行榜系统

- **个人排行榜**：保存在浏览器本地，记录你的历史分数与通关用时
- **全体排行榜**：跨玩家共享，显示「排名 + 昵称 + 得分」
- **昵称系统**：每位玩家**第一次打开游戏**时必须设置昵称；昵称全局唯一，不能与其他人重复
- 首次打开设置昵称后，游戏结束时得分会自动同步到全体排行榜（仅保留最高分）
- 修改昵称：主菜单按 N（同样要经过唯一性检查）

### 全体排行榜的云端配置（可选，约 5 分钟）

游戏默认是「本地模式」（个人排行榜可用，全体排行榜不可用）。要启用全体排行榜：

1. 注册 [Supabase](https://supabase.com)（免费）并创建项目
2. 进入项目 → **SQL Editor** → 执行 `supabase-setup.sql` 中的建表语句
3. 复制 **Project URL** 和 **anon public key**（项目 → Settings → API）
4. 填入 `config.js` 中的 `SUPABASE_URL` 和 `SUPABASE_ANON_KEY`
5. 保存并重新部署

> 说明：anon key 只能访问开启了 RLS 的受限数据；本游戏的表仅存昵称与分数，公开可读写。如果暂时不配置云端，游戏照常可玩。

## 📦 本地运行

直接双击 `index.html`（推荐 Chrome / Edge），无需安装任何环境。

## 🌐 部署到 GitHub Pages

1. 把本目录推送到 GitHub 仓库（仓库根目录需包含 `index.html`）
2. 进入仓库 → **Settings → Pages**
3. Source 选择 **Deploy from a branch**，分支选 `main`，目录选 `/ (root)`
4. 保存后等待 1-2 分钟，访问 `https://<你的用户名>.github.io/<仓库名>/` 即可

## ✨ 游戏内容

- 敌人：小型侦察舰 / 中型护卫舰 / 重型战列舰 / 星际母舰（Boss，每 5 波出现）
- 道具：W 武器升级（最高四连发）· M 导弹补给 · S 护盾 · H 生命
- 通关条件：通过第 10 波（含 Boss），通关后可继续无尽模式冲击更高分
