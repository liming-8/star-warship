星空战舰 - 2D 太空射击游戏
============================

【玩法简介】
  驾驶你的战舰在宇宙中迎击一波波敌方战舰，
  使用子弹和导弹摧毁敌人，争取更高分数。
  每 5 波会出现一艘星际母舰（Boss），击毁可获得大量分数！

【昵称系统】
  · 第一次打开游戏时，必须先为自己设置一个昵称（2-12 个字符，支持中文）
  · 昵称全局唯一，不能与其他玩家重复
  · 主菜单按 N 可以随时修改昵称（同样要经过唯一性检查）
  · 昵称与得分会显示在「全体排行榜」上
  · 若暂时无法连接排行榜服务器，可选择「离线模式继续」，
    此时昵称唯一性暂不生效，游戏照常可玩

【排行榜系统】
  · 排行榜分为「全体排行榜」和「个人排行榜」两个页面
    - 全体排行榜：所有玩家的昵称 + 得分排名（前 50 名，页面显示前 10 名），
      前三名金/银/橙高亮，自己的名字会高亮显示
    - 个人排行榜：本机保存的「分数排行」和「通关时间排行」各取前 5 名
  · 打开排行榜：主菜单点击「排行榜」按钮或按 T（游戏中按 T 会暂停并打开）
  · 切换榜单：点击标签，或按 1（全体）/ 2（个人）
  · 再按 T / ESC 返回原界面
  · 通关后可按回车继续无尽模式，冲击更高分

【全体排行榜的云端配置（可选）】
  默认是「本地模式」：个人排行榜可用，全体排行榜显示未配置提示。
  要启用全体排行榜（跨玩家共享、昵称全局唯一），请按 README.md 或
  config.js 中的说明配置 Supabase 免费云数据库（约 5 分钟）：
    1. 注册 https://supabase.com 并创建项目
    2. SQL Editor 中执行 supabase-setup.sql
    3. 把 Project URL 和 anon key 填入 config.js
  配置后，每局结束的得分会自动上传，仅保留你的历史最高分。

【操作说明】
  移动       W A S D 或 方向键（也可直接移动鼠标控制）
  射击       空格 或 鼠标左键（按住可连发）
  导弹       X 键 或 鼠标右键（自动追踪目标，范围爆炸伤害）
  暂停       P
  静音       M
  排行榜     T（主菜单中）
  修改昵称   N（主菜单中）

【道具说明】
  W   武器升级（最高 4 级：单发 → 双发 → 三发 → 四发）
  M   导弹补给（+6 发）
  S   护盾（抵挡一次伤害）
  H   生命 +1

【游戏机制】
  · 敌人分为：小型侦察舰、中型护卫舰、重型战列舰、星际母舰（Boss）
  · 通过第 10 波（含 Boss）即通关，通关后记录最快用时
  · 波次清空有额外奖励分
  · 最高分自动保存在浏览器本地

【如何运行】
  双击打开 index.html 即可开始游戏（推荐使用 Chrome / Edge 浏览器）。
  游戏部署到 GitHub Pages 后，也可以直接通过网址在线游玩。
